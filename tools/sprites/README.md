# Sprite and avatar generators (moved here 2026-09-12)

The Python scripts that built the portfolio's pixel avatars and costume sprites, plus five
test renders. They were written at the vault root and use paths relative to it
(`portfolio/assets/…`), so **run them from the vault root**, e.g.

```bash
cd "~/developer/A priyam ka patora" && python3 portfolio/tools/sprites/make_sprites.py
```

One-off tooling from 1 Sep 2026; not part of the deployed site.
